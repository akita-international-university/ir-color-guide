# Exploratory Desktop Color Palettes

> [!CAUTION]
> **AUTO-GENERATED — DO NOT EDIT**
>
> The JSON files in this directory are automatically generated from [`../palettes.yml`](../palettes.yml) by [`../scripts/build.py`](../scripts/build.py). Any manual edits will be overwritten the next time the build script is run.
>
> To update the palettes, edit `palettes.yml` and run `poetry run build`.

This directory contains one JSON file per palette, formatted for use as custom color palettes in [Exploratory Desktop](https://exploratory.io/).

## How to use

> [!TIP]
> See the official Exploratory documentation on [How to Create Custom Color Palette](https://exploratory.io/note/exploratory/How-to-Create-Custom-Color-Palette-rQl5ciH6) for more details.

1. Locate the `palettes` directory of your Exploratory Desktop local repository. By default, it is located at:
   ```
   C:\Users\<YourUsername>\.exploratory\palettes
   ```
2. Copy the JSON files from this directory into the `palettes` directory above.
3. Restart Exploratory Desktop if it is currently running.

The palettes will then appear as custom color palettes in Exploratory Desktop.
